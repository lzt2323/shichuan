File: A-native-light.png

Use case: ui-mockup.
Generate a beautiful, high-fidelity, implementable desktop UI design presentation image for 拾传 / PickDrop, a compact LAN file transfer group app. This is a design proposal for the user to choose, NOT a screenshot of an implemented app. Landscape design board, approximately 1600x1100, very crisp readable simplified Chinese UI, front-on flat screen design, no photographic devices, no perspective, no 3D logos.
Three carefully aligned regions: large main expanded app at left on a subtle neutral desktop swatch; upper right a small desktop-crop panel showing TOP-EDGE COLLAPSED state; lower right a small desktop-crop panel showing SIDE-EDGE COLLAPSED state. Use visible thin work-area boundary lines in the two right panels so physical attachment to the top and right edges is unmistakable. Top collapsed state is a short flat rectangular tab about 140x20 logical pixels, flush against the TOP boundary of desktop work area BELOW the system menu bar, with only lower corners slightly rounded. It is NOT a floating pill, oval, capsule, dynamic island, or a fake hardware notch. Side state is a thin straight vertical rectangular tab about 20x86 pixels flush to the right boundary, with a subtle accent rail and compact group glyph. Top tab shows small transfer icon + "工作资料" + tiny count "2". Label right panels "顶部收起" and "侧边收起". Main panel label "自由悬浮".
The main app has a clear drag affordance in its header, a group selector titled "工作资料", understated pin, dock and close icons. One concise connection indicator "2 台在线"; do not repeat connection badges or device names everywhere. Required file-transfer functionality: select files, read file cards, see sender or direction, drag files out, read and send short text. Show a real example file "设计稿.fig" with "12.8 MB", a thumbnail image file "封面.png" with "2.4 MB", an in-progress "视频.mov" with progress "68%", one short note "这一版可以发了". Compose/footer entry placeholder "发到工作资料…" with small plus and send-arrow buttons. Put secondary open/save actions behind a single understated overflow menu, not rows of redundant tiny text buttons. Use clean consistent 1.5px icons, strong text hierarchy, readable dark/body text and restrained metadata; accessible contrast. Typographic UI scale 13-14px body, 15px header at logical screen size, artwork may scale up for review. NO user's actual private screenshot, no URLs, no credentials, no device identifiers. NO marketing hero, giant banner inside app, ornamental charts, side navigation dashboard, crowded desktop icons, lorem ipsum, meaningless badges. Plenty of considered spacing but keep a genuinely compact utility. No code or implementation instructions in the image.
Art direction A: a sophisticated native light macOS utility, quiet precision, inspired by the clarity of Things and the lightweight function of Dropover without copying either. Main window proportion approximately 360x480 logical px, a vertical compact file conversation. Pearl-white #FAFBFD content, very subtle translucent cool-gray header, charcoal #202735 text, system blue #3478F6 as the ONLY main accent, tasteful pale blue selection, soft gray metadata, 14px corner radius and restrained realistic soft window shadow. NO green tint. Header minimal, under it a small slim segmented switch "全部" / "文件" / "消息". Body uses unified full-width chronological file rows with crisp file-type tiles, NOT alternating chat bubbles. A medium photo thumbnail embedded in one full-width card; note as a small quiet line with sender glyph, not huge chat bubble. The progress row has a 2px blue progress rail. Generous balance with only 3 file items and a note. App primary file actions remain a small arrow/ellipsis on hover. Board background near-white pale gray. Upper-left board title exactly "A · 轻白原生", below it a small subtitle "清晰 · 安静 · 原生感". Footer small line "视觉提案 · 待选择". The right-state panels use the same light white/blue tab materials, show an uncluttered neutral blue-gray desktop behind them. Render the UI beautifully and realistically, better typography and proportions than a generic chat app.

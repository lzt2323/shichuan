# 多端群：实现与验收

本说明对应 v0.5.1 多端群内测版。0.4.1 及更早版本不包含这些变化。

## 用户可见行为

新建群使用 `pickdrop-peer-v1`（`mode: peer`、`authVersion: 3`）。Mac、Windows、Linux TUI 和 Android 原生应用各自保存群副本。创建者退出程序后，已经加入的在线成员继续发送文字、邀请新成员和交换文件，无需选举新群主。

创建者仍拥有改名、移除成员、解散群的管理权限；在线成员提供传输服务，不会因此获得管理权限。Android 仅保证应用前台时参与，系统后台限制或进程终止会使其离线。iOS、Expo Go 和网页当前只能使用旧托管群，不能充当新群副本节点。

消息元数据同步，附件不强制全员复制。发送者保留原件，接收者下载并校验后拥有副本。只有持有者离线时，其他设备仍能看到已有文件记录，下载显示等待；任一持有者重新可达后即可重试。没有任何副本的文件无法凭哈希恢复。Linux TUI 的等待任务每 10 秒重试，关闭后台服务后任务需重新发起；手机等待任务可恢复。当前没有字节级断点续传。

“退出群”同步退出事件；“解散群”同步创建者签名的解散事件；“从本机移除”只移除本机列表。退出/解散时若所有其他成员都不可达，操作记录先落盘，保留群并提示等待同步后重试，避免误报已通知全群。至少一个其他副本接收后才清除本机列表。后续传播仍依赖持有事件的副本再次上线，不保证在所有这些副本永久丢失时送达。

## 同步与身份

- Ed25519 设备密钥签名群创建记录、成员授权和事件。群 ID 不随服务提供者变化。
- 事件包含父事件、因果时钟、作者及内容哈希，校验授权发生在该事件的因果历史中。
- 重复事件幂等合并，离线并发消息在重连后合并。撤销与并发旧身份事件冲突时优先撤销；失效授权派生的成员和消息也隔离。创建者授予的设备身份不能被普通成员旧分支覆盖；普通成员对同一设备 ID 的不同公钥授予发生冲突时隔离，需创建者裁定。被撤销者重新加入需要相应授权。
- 请求证明绑定用途、群、时间和随机数，拒绝过期与重放。发现地址是线索，认证通过后才同步历史。
- 同步每批最多 128 个事件，交换已知事件 ID；缺少成员授权链时允许受限上传有效签名事件，未确认授权前不返回群历史。
- 本机 UI 沿用本机收件箱接口，跨设备使用签名协议；不向成员分发创建者的旧群 bearer 凭据。
- 两个签名消息使用同一个消息 ID 且内容冲突时，两者均从可见投影隔离，避免各端出现不同结果。日志保留事件；当前没有冲突处理界面。

签名不等于加密。本分支仍使用可信局域网 HTTP，不提供 TLS、端到端加密或公网中继，也不宣称与其他产品协议兼容。不要将端口暴露公网。

## 发现与跨子网

mDNS/UDP 广播每个真实副本的端点，服务实例标识包含群和设备，避免同群多端相互覆盖。完整邀请链接包含地址、邀请码和群 ID；也支持 IP、IP:端口加邀请码。

手动输入 `172.29.5.94` 时，仅探测该地址的目录端口 47321–47324，然后认证具体群端点，不扫描整个 /16。两台设备的 IPv4 看起来属于同一个大网段，并不能证明路由、掩码、防火墙或 Wi-Fi 客户端隔离允许连接。手动地址绕过组播发现限制，无法绕过网络隔离。

## 旧群升级

旧托管群保持原协议，不自动改写。由原托管设备显式升级：完整导出历史并构建签名快照、持久化，再切换服务；失败恢复旧配置和监听服务。旧 SQLite、原文件和备份保留。旧消息标注为创建者导入并保留原作者字段，不能伪称旧作者签名。

其他设备需要重新批准加入升级后的群。升级前应备份整个应用数据目录；不能只复制单个配置文件或把旧版程序直接覆盖运行在已升级的数据目录上。设备私钥丢失不能由邀请码恢复同一个密码学身份。

## Linux

当前发行形式仍是带 Node.js 的 x64/ARM64 TUI。后台模式和 systemd 用户服务均通过同一个 peer group manager，不需要常驻创建者。命令说明见 [Linux 指南](linux.md)。

源码 Electron 额外处理 X11/Wayland 差异：X11 支持自定义定位和贴边；原生 Wayland 使用系统窗口边框，避免依赖不受支持的窗口定位 API。有 DISPLAY 时默认选择 X11/Xwayland，并尊重明确传入的后端选项。此项仍需要对应 Linux 桌面实机验收。

## 自动验收与设备验收

自动化覆盖：三节点创建者退出后文字与二进制文件传输、持有者回归、同长度损坏文件重取、双向同步不死锁、事件篡改/重放拒绝、撤销与重新加入、授权票据撤销、并发日志合并、历史迁移、跨 /24 手动发现、群生命周期、窗口动画与圆角裁切。

执行入口：`pnpm check`、`pnpm test`、`pnpm mobile:check`、`pnpm mobile:export`、`pnpm desktop:peer`、`pnpm desktop:lifecycle` 以及原有桌面和 TUI smoke。Android 模块和完整应用应通过原生 Kotlin 编译。Linux 包脚本复制包含签名库的依赖闭包，在对应 Linux 架构 CI 上运行安装包 smoke。

本机 Mac 上的多进程、多 daemon、手机 HTTP 适配器互通测试不替代 Windows、Android 和 Linux 实机。发布前须在实际设备上验证：创建者退出；剩余两端互发；唯一文件持有者离线再回归；Android 前后台切换；Linux X11/Wayland；防火墙及不同 Wi-Fi 子网。当前未对大规模历史作容量承诺：日志尚无压缩，投影、已知 ID 列表和持久化成本随历史增长。

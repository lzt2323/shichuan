# 拾传 v0.5.0 · 多端群内测版

创建者退出程序后，已加入的在线成员可继续发送消息、邀请成员和互传文件。Mac、Windows、Linux TUI 与 Android 原生应用使用签名事件副本同步，文件按需从在线持有者获取，无副本在线时等待重试。创建者仍保留改名、移除成员和解散群的管理权限。

- 新增退出、解散、从本机移除、旧群升级与手动连接修复；默认群名递增并显示来源。
- 修复发现服务实例冲突、旧授权恢复、撤权与并发授权边界、同步数据泄露、文件校验及取消问题。
- 修复弹窗圆角和焦点环，改善收展过渡。Linux TUI 支持文件等待与自动重试；源码 Electron 对原生 Wayland 使用普通系统窗口。
- 修复 Mac 内测包签名，并在归档前验证签名完整性。

## 升级

建议所有设备一起升级。先备份完整应用数据目录，再在旧群原托管设备选择升级多端群；历史与原文件保留，其他成员需要重新批准加入。旧群不会自动改写。勿用旧版本直接打开已升级的数据目录。

Android 请安装新 APK，不能只更新 JS；节点服务仅在前台运行时保证参与。iOS、网页和 Expo Go 尚不能充当多端群节点。所有设备均离线时不提供云端投递；只有副本永久丢失时无法恢复文件。退出或解散时其他成员全离线，会保留待同步记录并提示重试。

## 验证与边界

发布前本地 261 项测试、真实三 Electron 进程创建者退出互传、桌面及 TUI 交互检查通过；Android 原生 Kotlin 编译通过。发行流水线在各平台构建安装包，Linux x64/ARM64 执行包内运行时验证。自动化不替代 Windows、Linux 图形桌面与 Android 跨设备真机验收。

本版仍为可信局域网 HTTP 内测应用，签名提供身份和完整性校验，不等于 TLS 或端到端加密。尚无公网中继或字节级断点续传。Mac 使用 ad-hoc 签名，未 Apple 公证；Android 内测使用公开测试证书。发行包统一附 SHA256SUMS.txt。

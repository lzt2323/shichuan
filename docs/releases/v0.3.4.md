# 拾传 v0.3.4 · Android 输入框图片粘贴

## 本版变化

- Android 在聊天输入框长按「粘贴」，图片直接显示在同一个输入框内，可继续输入文字、移除图片，再点击发送；不再使用独立预览栏或额外的粘贴图片按钮。
- 普通文字保留原生选择、复制和粘贴交互，支持中文输入；外接键盘可用 Ctrl+V 或 Shift+Insert 粘贴图片。
- 兼容 Android 剪贴板图片的换行 Base64 格式，保存图片草稿及其类型，发送失败可重试。
- 读取剪贴板期间切换群会取消导入，防止图片加入错误会话；加入输入事件顺序保护，避免界面刷新覆盖新输入的文字。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片 | `PickDrop-0.3.4-Mac-AppleSilicon.zip` |
| Windows x64 | `PickDrop-0.3.4-Windows.exe` |
| Android ARM64 | `PickDrop-0.3.4-Android-arm64-preview.apk` |
| Linux x64 终端版 | `PickDrop-0.3.4-Linux-x64-TUI.tar.gz` |
| Linux ARM64 终端版 | `PickDrop-0.3.4-Linux-arm64-TUI.tar.gz` |

Android 内测版 versionCode 升至 304，包名与测试签名沿用上一版，可直接覆盖安装同包名内测版，保留应用数据。此功能包含新的原生组件，需要安装新版 APK。

桌面退出旧版后替换应用，保留用户数据目录。Linux 先运行 `pickdrop stop`，解压新版后执行 `./pickdrop install`，再运行 `pickdrop open`。本版 Mac、Windows、Linux 安装包同步版本，保留已有功能。

所有平台来自同一发布标签，附 `SHA256SUMS.txt` 与 `ANDROID-BUILD.txt`。

## 验证与边界

源码检查、137 项自动化测试、手机类型检查和资源导出通过；组件布局已检查窄屏显示。统一发布流程再次执行检查并构建所有平台，安装包齐备后才发布。

Android 原生编译已验证，长按菜单、中文输入法和不同厂商剪贴板仍需真机验收；暂未接入输入法图片候选栏的插入接口。截图必须已复制为剪贴板图片，仅保存到相册的图片可通过「＋」或系统分享添加。单张最多 32 MiB，最多 10 张待发图片，添加时待发文件合计最多 64 MiB。

继续作为内测版发布：桌面包未正式签名或公证，Android 使用公开测试证书与独立内测包名，不包含 iOS IPA。

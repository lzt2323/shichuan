# 拾传 v0.4.1 · 图片预览与文件操作优化

## 本版变化

- 桌面与手机采用图片预览优先的文件卡片，点击图片查看大图，更多菜单提供保存、分享等操作；普通文件使用紧凑布局，文件名获得更多空间。桌面保留接收后拖出文件的操作。
- 手机返回、添加、更多和发送按钮统一使用线条图标，替换字号与形状不一致的字符箭头。图片预览有加载、失败重试与原文件已清理状态。
- 预览支持不超过 8 MiB 的 PNG、JPEG、WebP，文件通过大小与完整性校验后才显示本地图片。桌面沿用新到小文件自动接收，已接收图片显示缩略图；历史图片按需加载。手机仅为当前可见且不超过 2 MiB 的支持图片自动加载，2–8 MiB 图片点击后加载；离开可见区域或页面会取消未完成请求并释放预览占用。其他格式或较大图片可保存原文件后查看。
- 修复手机接收名为 `cache.json` 的文件时，缓存元数据覆盖原文件的问题。用户文件改放独立 `payload/` 目录，缓存信息与文件内容分离。
- 修复同时保存不同文件时系统面板冲突。手机保存和分享面板按顺序打开；iOS 等待预览或菜单关闭后再展示系统面板。取消、失败与重试继续保留原有语义。
- GitHub Android 构建增加 Gradle 依赖与构建缓存，跳过 Electron 二进制下载。日常可手动单独生成 APK；main 构建更新共享缓存，全平台打包改为手动预检或版本标签触发，减少重复构建。

- 桌面在解码前检查图片头中的尺寸，超过 4000 万像素的图片通过保存原文件查看，避免小体积、高压缩图片导致预览占用过多内存。

## 下载与升级

安装包由 GitHub Actions 统一构建，资产齐备后发布到同一 Release。

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片 | `PickDrop-0.4.1-Mac-AppleSilicon.zip` |
| Windows x64 | `PickDrop-0.4.1-Windows.exe` |
| Android ARM64 | `PickDrop-0.4.1-Android-arm64-preview.apk` |
| Linux x64 终端版 | `PickDrop-0.4.1-Linux-x64-TUI.tar.gz` |
| Linux ARM64 终端版 | `PickDrop-0.4.1-Linux-arm64-TUI.tar.gz` |

Android versionCode 为 401，沿用 `app.pickdrop.mobile.preview` 内测包名，可覆盖升级并保留数据。本版加入原生 SVG 支持，必须安装新 APK，不能仅更新 JS。桌面退出旧版后替换应用；Linux 更新前执行 `pickdrop stop`。本版不包含 iOS IPA。

从 v0.4.0 升级无需新的历史格式迁移；从更早版本升级请先阅读 [v0.4.0 迁移说明](v0.4.0.md)，退出应用并备份完整数据目录。预览缓存清理不影响已另存的文件和系统相册。

## 验证与边界

本轮本地 217 项自动化测试、源码检查、手机类型检查及 iOS/Android JS 资源导出通过。桌面回归覆盖图片缩略图与大图、文件操作、最小窗口、多群传输及窗口动作；手机 Web smoke 覆盖图片占位、图片与普通文件菜单、配对、多群草稿与窄屏布局。新增测试覆盖图片预览校验、缓存保护、同名文件内容保留及跨文件保存串行。

浏览器界面检查与 JS 导出不替代原生真机验收。Android/iOS 图片解码、相册保存、系统分享面板和实际网络行为尚需设备验证；Android 大图当前提供适配屏幕的查看，iOS 支持系统滚动视图缩放。手机网页模式仅用于界面预览，图片接收与系统保存需原生客户端。

继续作为内测版发布：桌面包未正式签名或 macOS 公证；Android 使用公开测试证书与独立内测包名。本版不改变签名配置。安装包附 `ANDROID-BUILD.txt` 与 `SHA256SUMS.txt`。仅适合可信局域网，HTTP/WebSocket 尚无 TLS 或端到端加密，不应开放公网。

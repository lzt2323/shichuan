# 拾传 v0.3.2 · 拾点 Logo 与终端工作台

采用新的 A「拾点」标志：青绿色托举形接住一枚小方块，表达轻轻拾起、传递文件。桌面应用、Windows 可执行文件和 Android 应用图标同步更新；macOS 菜单栏使用独立单色模板图标，适应深浅色菜单栏。

## Linux 终端体验

- 青绿工作台：宽屏三栏、中等宽度双栏，窄屏或矮屏聚焦会话；调整窗口大小时实时切换。
- 改善中文、emoji、长消息分页、邀请二维码完整显示和传输失败提示，切换群时隔离任务与审批操作。
- `./pickdrop install` 安装快捷命令；`pickdrop open` 打开界面，`pickdrop start` 后台启动，`pickdrop stop` 关闭后台及连接的终端界面。重复停止也可安全执行。
- 下载默认沿用上一次成功使用的保存目录，重启后继续保留；首次默认为 `~/Downloads/拾传`。

## 验证与边界

发布前运行源码检查、95 项自动化测试、移动端类型检查及资源导出；终端已验证 160×40、120×30、80×24、60×18 布局，流水线在 Linux x64/ARM64 分别打包并验证启停与消息操作。各平台安装包统一构建成功后发布。

当前仍为内测版：Mac 与 Windows 未进行正式开发者签名或公证；Android 使用公开测试证书和独立内测包名；没有 iOS IPA。Linux/SSH 交互及 Windows、Android 实机使用仍需实际设备验收。HTTP 局域网协议不应直接开放公网。完整功能边界见 README。

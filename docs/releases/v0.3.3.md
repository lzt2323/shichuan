# 拾传 v0.3.3 · 方向键工作台与图片粘贴

## Linux 终端交互

- 用 ↑ / ↓ 选择工作空间、消息与操作，用 ← / → 在区域之间移动。切换群后立即显示对应消息和任务，无需再次按 Enter。
- 选中文件后进入操作区，可下载、重试或调整保存位置；仅移动焦点不会开始下载。保存目录可单独设置并在重启后保留。
- 优化深色背景、工作空间行距和宽窄屏布局；折叠长链接，改善中文、emoji、长文件名、草稿光标及小窗口显示。

## Mac 与 Windows 图片粘贴

- macOS 用 ⌘V、Windows 用 Ctrl+V 粘贴剪贴板图片，在输入框上方预览后按 Enter 或发送按钮发送，可先移除不需要的图片。
- 发送失败的图片保留供重试，普通文字粘贴不受影响。一次最多 10 张，单张最多 32 MiB，合计最多 64 MiB。
- 增加原生剪贴板兼容，并识别文件引用格式，避免在原生兼容流程中误发复制文件的缩略图。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片 | `PickDrop-0.3.3-Mac-AppleSilicon.zip` |
| Windows x64 | `PickDrop-0.3.3-Windows.exe` |
| Android ARM64 | `PickDrop-0.3.3-Android-arm64-preview.apk` |
| Linux x64 终端版 | `PickDrop-0.3.3-Linux-x64-TUI.tar.gz` |
| Linux ARM64 终端版 | `PickDrop-0.3.3-Linux-arm64-TUI.tar.gz` |

退出旧版后替换应用或解压目录，保留用户数据目录即可沿用已有群和设置。Linux 先运行 `pickdrop stop`，解压新版后执行 `./pickdrop install` 更新快捷命令，再运行 `pickdrop open`。Android 内测版 versionCode 递增至 303，可覆盖升级同包名内测版。

所有安装包来自同一标签，附 `SHA256SUMS.txt` 和 Android 构建报告。

## 验证与边界

本地源码检查、129 项自动化测试、手机类型检查及资源导出通过。桌面页面验证图片预览、移除、单独发送、图文发送及普通文字粘贴，上传文件字节与 SHA-256 校验通过。TUI 实际 Ink 输出覆盖 160×40、120×30、80×24、60×18。各平台安装包全部构建成功后统一发布。

原生剪贴板兼容已通过单元测试，仍需 Mac/Windows 原生安装包以及 Linux/SSH 完整交互实机验收。当前继续作为内测版发布：桌面包未正式签名或公证，Android 使用公开测试证书与独立内测包名，不包含 iOS IPA。

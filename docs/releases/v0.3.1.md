# 拾传 v0.3.1 · 加群审批体验修复

桌面加入申请从聊天记录中移到窗口顶部的固定提醒条。无论正在看哪条消息，都能看到申请设备，并直接允许或拒绝；多条申请可点「查看全部」集中处理。成员页面也增加审批入口。

处理后提醒自动更新；其他成员已批准、拒绝或申请过期时同步移除。申请更新不会重建聊天记录或清空正在输入的文字，不会自动弹窗打断操作。

## 下载

所有平台放在同一个 Release，选择与你的系统对应的一项即可：

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片 | `PickDrop-0.3.1-Mac-AppleSilicon.zip` |
| Windows x64 | `PickDrop-0.3.1-Windows.exe` |
| Android ARM64 | `PickDrop-0.3.1-Android-arm64-preview.apk` |
| Linux x64 终端版 | `PickDrop-0.3.1-Linux-x64-TUI.tar.gz` |
| Linux ARM64 终端版 | `PickDrop-0.3.1-Linux-arm64-TUI.tar.gz` |

本次交互修复在桌面端；协议兼容 v0.3.0 的手机与 Linux。其他平台同步版本以保持统一发布。附 SHA256SUMS.txt 与 Android 构建报告。

## 验证与边界

实际 Electron 回归验证覆盖 45 条历史消息、280×340 最小窗口、固定审批入口、多申请批准/拒绝、其他成员处理后的同步，以及输入草稿和消息 DOM 保留。发布流水线运行原有协议测试和各平台构建。

当前仍为内测版：Mac 未签名、公证；Android 使用公开测试证书和独立内测包名；没有 iOS IPA。跨网段需要服务地址可达，当前不内置 SSH 隧道，HTTP 局域网协议不应直接开放公网。完整功能边界参见 README。

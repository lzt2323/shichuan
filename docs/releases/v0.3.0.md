# 拾传 v0.3.0 · 全平台内测版

本次将电脑、Android 和 Linux 终端客户端集中在同一个 Release。请只下载与你的系统对应的一项，不需要安装全部文件。

| 系统 | 下载文件 | 启动方式 |
| --- | --- | --- |
| Mac Apple 芯片 | `PickDrop-0.3.0-Mac-AppleSilicon.zip` | 解压后打开 PickDrop.app |
| Windows x64 | `PickDrop-0.3.0-Windows.exe` | 直接运行 |
| Android ARM64 | `PickDrop-0.3.0-Android-arm64-preview.apk` | 在手机上打开 APK 安装 |
| Linux x64 | `PickDrop-0.3.0-Linux-x64-TUI.tar.gz` | 解压后运行包内 pickdrop |
| Linux ARM64 | `PickDrop-0.3.0-Linux-arm64-TUI.tar.gz` | 解压后运行包内 pickdrop |

Linux 包是终端客户端，适合桌面终端、SSH 和无图形桌面的主机；已包含 Node.js 运行时。Linux 包在 Ubuntu 24.04 对应架构构建验证，不宣称兼容 Alpine/musl。手机包内置运行资源，不需要 Expo Go 或开发服务器。

## 本版改进

- 新增 Linux 群传输终端界面、命令行操作和可选后台运行。
- 电脑增加传输网络选择，邀请使用可供其他设备访问的地址，修复本机创建群时二维码错误使用 127.0.0.1 的问题。
- 增加 DNS-SD/mDNS 局域网发现，手机加入以附近设备为入口，保留扫码与手动连接。
- 各平台安装包来自同一发布标签；全部构建成功后一起发布，SHA256SUMS.txt 覆盖所有安装包和 Android 构建报告。

设备需要处于可互通的网络。访客 Wi-Fi 隔离、防火墙或禁用组播可能阻止发现/连接；扫描二维码不能绕过网络隔离。群由创建它的电脑或 Linux 主机托管，主机必须保持运行。

## 内测边界

Android 使用公开 Expo 测试证书和独立包名 `app.pickdrop.mobile.preview`；此证书不能证明发布者身份，不是正式商店签名。Mac 未进行开发者签名、公证。当前没有 iOS IPA、Intel Mac 安装包或 Linux 图形窗口版。

当前协议为可信局域网 HTTP/WebSocket，未实现 TLS、端到端加密、公网中继、断点续传或群主机故障转移。构建和自动化测试不等于 Android 真机、全部发行版及真实多网卡环境验收。

下载后可对照 SHA256SUMS.txt 校验文件；不要安装来源不明的同名文件。ANDROID-BUILD.txt 提供 APK 包名、SDK 和签名检查结果。

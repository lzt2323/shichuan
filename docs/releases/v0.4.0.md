# 拾传 v0.4.0 · 扫码连接、贴边小猫与直接保存

## 本版变化

- 手机以扫码加入为主入口，保留邀请链接与电脑地址；移除陌生群搜索页及周期网段扫描。已有群在前台自动重连，主机地址失效时重新扫码更新地址，验证主机身份后保留原授权、聊天和草稿。已撤销的授权不会因扫码重新生效。
- Android 保留 NSD/UDP 地址发现，iOS Bonjour 解析失败采用有界退避重试。手机发现结果仅保留已配对的群及主机。
- 图片默认保存到系统相册，普通文件通过系统文件选择器保存，分享独立。取消保存不显示成功，保存失败可复用缓存重试。正在保存的文件受保护，同文件接收、重试和导出串行执行。
- 桌面与手机统一奶油白、松绿和薄荷色。桌面贴边入口改为原创小猫，文件拖入时伸爪并展开收件区；删除重复操作说明。macOS Dock 图标增加透明留白。
- 修复窄窗口成员文字竖排、贴边后快速切换窗口不收起、顶部小猫拖出丢失捕获，以及退出期间重新激活旧窗口的连接错误。
- 群历史迁移至 SQLite，按页读取并增量同步。客户端保留有界消息，旧附件按需接收，不再打开群就下载全部历史文件。
- 接收缓存默认最多 7 天、合计 512 MiB，保护活动文件；提供清理入口。群主可分页选择删除托管原件，消息保留已清理标记。已另存的文件与手机相册不受缓存清理影响。
- 桌面与 TUI 共用下载模块，各端共用历史合并规则。移除重复下载代码、失效 IPC、手机附近搜索组件和网段扫描任务；手机文件操作与存储页面独立成组件。

## 下载与升级

| 系统 | 安装包 |
| --- | --- |
| Mac Apple 芯片 | `PickDrop-0.4.0-Mac-AppleSilicon.zip` |
| Windows x64 | `PickDrop-0.4.0-Windows.exe` |
| Android ARM64 | `PickDrop-0.4.0-Android-arm64-preview.apk` |
| Linux x64 终端版 | `PickDrop-0.4.0-Linux-x64-TUI.tar.gz` |
| Linux ARM64 终端版 | `PickDrop-0.4.0-Linux-arm64-TUI.tar.gz` |

Android versionCode 为 400，沿用 `app.pickdrop.mobile.preview` 内测包名，可覆盖升级并保留数据。本版新增原生保存模块，必须安装新 APK，不能仅更新 JS。桌面退出旧版后替换应用；Linux 更新前执行 `pickdrop stop`。

首次加载旧历史时保留 `history.pre-sqlite.json` 并迁入 `history.sqlite`，此后 `history.json` 仅保存设备及授权元数据。升级前请退出应用并备份完整数据目录。迁移后不要直接用旧版打开同一目录；如需回退，应恢复完整升级前备份。授权文件损坏不会自动回滚备份，避免复活已撤销的凭据；缺失历史数据库时保留原文件并隔离该群。

草稿持续保留，由用户发送或删除；失去对应群的草稿可重新关联。托管原件不自动过期，由群主决定何时清理；接收缓存可随时清理并重新获取。

## 验证与边界

发布流程执行源码检查、全部自动化测试、手机类型检查、iOS/Android JS 资源导出，并在各平台构建 Mac、Windows、Android 和 Linux x64/ARM64 安装包。资产齐备后统一发布，附 `ANDROID-BUILD.txt` 与 `SHA256SUMS.txt`。

本轮本地 204 项自动化测试、源码检查、手机类型检查和两平台资源导出通过；手机 Web smoke 覆盖真实审批、多群、已配对链接与草稿保留。桌面回归覆盖双实例群传输、成员管理、窗口拖动、最小布局、审批和退出。手机自动化覆盖扫码链接身份验证、地址更新、保留授权/草稿、保存取消以及同文件并发；浏览器 UI 检查与 JS 导出不替代原生真机验收。

Android/iOS 实际相册保存、路由器组播行为和 Windows 实机拖放仍需设备验收；本版不包含 iOS IPA。扫码解决地址定位，不能绕过访客网络隔离或防火墙。已配对设备自动重连是尽力恢复，无法定位新地址时可重新扫码。

继续作为内测版发布：桌面包未正式签名或 macOS 公证；Android 使用公开测试证书与独立内测包名。仅适合可信局域网，HTTP/WebSocket 尚无 TLS 或端到端加密，不应开放公网。本轮不引入公网发现或中继服务器。

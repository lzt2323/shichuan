# 拾传 v0.2.1（内测）

多人在同一个传输群里发送文件和文字，采用蓝白会话界面。

- 桌面支持自由拖动、左右及顶部贴边，收起为小半球，补充平滑动画与缩放。
- 邀请窗口提供短期二维码和六位码，现有成员审批后加入。
- 手机源码接入多群、群成员审批、文件待发、真实进度、取消重试、SHA-256 校验及系统分享。
- 建立源码版本、自动检查与安装包发布流程。

## 下载

- `PickDrop-0.2.1-Mac-AppleSilicon.zip`：Apple Silicon Mac，解压后将 PickDrop.app 放入“应用程序”。暂不提供 Intel Mac 包。
- `PickDrop-0.2.1-Windows.exe`：Windows x64 便携版，下载后直接运行，无需安装向导。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

## 当前限制

桌面包未正式签名或公证，系统可能显示未知开发者提示。本版本用于可信局域网，通过 HTTP/WebSocket 传输；请勿开放到公网。创建群的电脑需要保持运行。

手机本次提供源码及双平台 JavaScript 构建验证，不包含 APK/IPA。文件提供商、系统分享、权限、后台与锁屏传输仍需原生真机验收；iOS 分享接收使用 Expo 实验性接口。Windows 包完成构建并不等于完成 Windows 实机交互测试。

# Linux TUI 方向键交互验收

这份清单用于当前源码的方向键交互改动。修改和本地测试完成不代表已经打包或发布；GitHub Release 的旧安装包保持原样，发布前还需验证目标 Linux 和 SSH 终端。

## 自动化检查

```sh
pnpm test
pnpm check
pnpm tui:visual
```

`tests/tui-navigation-view.test.js` 捕获实际 Ink 输出，覆盖 160×40、120×30、80×24、60×18、中文与 emoji 长文件名、即时功能预览、按群隔离任务、状态对应操作、长草稿光标和终端色彩回退。`tests/tui-ui.test.js` 验证真实键盘输入与 RPC 调用，`tests/tui-preferences.test.js` 验证保存路径持久化和失败边界。具体测试结果以本次命令输出为准。

`pnpm tui:visual` 的图片来自演示数据和 ANSI 字符渲染，用于检查尺寸和布局；不代表通过 Linux 图形终端或 SSH 实机验收。

## 准备

准备两个可切换的群，每群至少包含不同的文字消息和可下载文件。一个文件名包含中文及 emoji，一条文字包含多行内容和长链接。保证两个群内容足够不同，便于判断是否串群。使用空测试目录作为下载目标，记录此前默认保存目录。

按 160×40、120×30、80×24、60×18 各执行一次主要路径。实际终端分别检查真彩色、256 色和基础色环境；确认终端报告的能力与自身支持一致，不只修改 `TERM` 名称伪装能力。

## 方向键与联动

- 启动后处于消息浏览区。输入普通字符不会直接发消息，也不会自动进入编辑。
- 按 ← 到工作空间，再用 ↑ / ↓ 经过两个群。每次选中群，顶部群名、消息内容和当前群任务立即联动，不需 Enter；较慢响应不能把已离开的群内容填回来。
- 返回前一个群时，保留该群之前选中的消息；外来消息刷新不应跳走当前焦点。
- 用 ↑ / ↓ 选“发送消息”“发送文件”“传输任务”“保存位置”。右侧立即显示对应预览，旧消息不残留。
- 只用 ← / → 在工作空间、消息和操作区域切换。全屏只有当前区域的选中项具有操作高亮。
- 窄屏操作区替换消息区；返回仍停留原消息。调整窗口大小时焦点、选中项和草稿不丢失。

## 下载、目录与任务

- 选中文件，用 → 进入操作区，核对文件名和默认保存路径；仅用方向键切换不会发出下载请求。
- Enter 下载后只创建一个任务，重复确认排队或进行中的同一下载不产生重复任务。
- 进行中显示状态，失败显示“重试下载”，完成显示“查看保存位置”。另一个群的同名文件和任务不影响当前消息操作。
- “更改保存位置”可用 → 进入；修改后 Enter 下载并记住目录；Esc 取消不保存、不下载。
- 工作空间的“保存位置”可独立保存目录，无需启动下载。退出并重新启动后仍显示新目录；不可写路径失败时旧目录保持。
- 对文字消息只提供完整内容等适用操作。长链接在列表中折叠，详情可滚到末尾，再按 ← 返回。
- 传输失败、待批准和等待加入的计数能在状态栏看到，不被启动说明遮挡。

## 发送

- 先明确选定目标群，再通过工作空间进入“发送消息”。当前群名始终可见；输入中文、组合 emoji，用左右键编辑，字符不拆开。
- Esc 或行首 ← 返回工作空间保留草稿；再次进入可继续编辑。Enter 只向显示的当前群发送一次。
- 进入文件选择器，用 → 进入目录，Enter 或空格勾选文件，移到末尾“发送已选文件”，Enter 发送。整条路径不需要 Ctrl+S。
- 未勾选文件时确认发送显示提示，不发起空上传；“输入其他路径”可以通过列表选中并进入。
- SSH 下选中的是服务器上的文件，上传目的群应与顶部显示一致。

## 视觉与小窗口

- 深色背景无大片灰底；基础色终端仍有可辨认的选中标记，不能只依靠颜色区分焦点。
- 工作空间各项行距一致，标题和内容对齐，没有功能项之间的大块空白。
- 四档常用尺寸均无字符换行溢出或底部提示遮挡；60×18 下文件操作四项都能看到。
- 更短窗口下移动到最后一个操作时，“返回消息”和当前选择仍可见；过小窗口给出调整提示。
- 长文件名和链接不挤出后续消息；长草稿光标移动到开头或结尾时仍位于可视范围。

## 发布前

本地验收后再决定版本、构建与发布。Linux x64 和 ARM64 包均需执行现有打包 smoke，并用真实终端至少跑通“启动 → 切群 → 选消息 → 下载 → 改目录 → 重启保留目录 → 退出”路径。验收记录应区分自动化通过、字符预览通过和仍待实机确认的项目。
